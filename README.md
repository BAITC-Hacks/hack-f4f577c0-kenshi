# hack-f4f577c0-kenshi

Два решения репетиционных заданий:

- `triage.py` — классификация обращений и черновики ответов;
- `filter_events.py` — отбор критичных событий из JSON.

## Первый кейс: triage.py

Репетиционное задание хакатона (команда kenshi): простой разбор обращений студентов
с автоматической категоризацией и черновиками ответов.

## Что делает скрипт

`triage.py` читает файл `messages.txt` (одно обращение на строку) и для каждого обращения печатает:

- порядковый номер и исходный текст обращения;
- категорию — **справка**, **жалоба** или **другое** — с указанием сработавшего ключевого слова;
- черновик вежливого ответа на русском (2–3 предложения), подставленный по шаблону категории
  и дополненный конкретной темой обращения.

В конце выводится сводка по количеству обращений в каждой категории.

Скрипт написан на чистом Python 3 (проверено на 3.12) — без внешних библиотек, без обращений
к LLM и без API-ключей. Вывод принудительно переключается в UTF-8
(`sys.stdout.reconfigure`), поэтому русский текст корректно читается в консоли Windows.

## Как запустить

```
python triage.py
```

По умолчанию берётся `messages.txt` из текущей папки. Можно указать другой файл:
`python triage.py my_messages.txt`.

## Как устроена классификация

Классификация — правила по ключевым словам, без машинного обучения. Текст обращения приводится
к нижнему регистру и проверяется на вхождение корней слов (список `RULES` в `triage.py`):

- **справка** — `справк`, `выписк`, `подтверждени`, `документ о`;
- **жалоба** — `очеред`, `холодн`, `пропал`, `не работает`, `сломал`, `грязн`, `шум`, `задержк` и т. п.;
- **другое** — если ни одно правило не сработало.

Правила проверяются по порядку, побеждает первое совпадение. Отдельно работает словарь `TOPICS`:
он определяет тему обращения (столовая, Wi-Fi, парковка, консультация, справка о месте учёбы)
и подставляет её в шаблон ответа — так черновик получается не безликим. Если тема не распозналась,
в ответ подставляется цитата самого обращения.

Чтобы добавить новое правило или шаблон, достаточно дописать строку в `RULES`, `TOPICS` или `TEMPLATES`.

## Пример вывода

```
Обработка файла: messages.txt (обращений: 5)
======================================================================

Обращение №1: Как получить справку о месте учёбы?
Категория: справка (ключевое слово: «справк»)
Черновик ответа: Здравствуйте! По вашему вопросу справки о месте учёбы сообщаем: заявку
можно оформить в деканате или через личный кабинет, при себе достаточно студенческого билета.
Документ готовится в течение 3 рабочих дней, о готовности мы сообщим дополнительно.

Обращение №4: Пропал Wi-Fi в корпусе B.
Категория: жалоба (ключевое слово: «пропал»)
Черновик ответа: Здравствуйте! Спасибо, что сообщили о проблеме — мы зафиксировали обращение
по поводу доступа к сети Wi-Fi. Информация уже передана в ответственную службу, ситуацию
проверяем. О принятых мерах сообщим вам в течение 2 рабочих дней.

======================================================================
Итого: другое — 2, жалоба — 2, справка — 1
```

Сроки и службы в черновиках — примерные значения шаблонов.

## Второй кейс: filter_events.py

`filter_events.py` читает `events.json` и выводит только события с уровнем
`critical` в исходном порядке. Уровень сравнивается без учёта регистра:
например, значения `critical` и `CRITICAL` обрабатываются одинаково. После
событий скрипт печатает одну итоговую строку с их количеством. Для работы
достаточно стандартной библиотеки Python; вывод настроен на UTF-8, как в
`triage.py`.

Запускать из корня репозитория:

```
python filter_events.py
```

`events.json` — массив объектов. У каждого объекта есть строковое поле `event`
с названием события и строковое поле `level` с уровнем важности. В приложенном
файле восемь событий с уровнями `critical`, `info` и `warn`. Например:

```
{"event": "disk 90%", "level": "critical"}
```

На приложенных данных вывод будет таким:

```
disk 90%
payment failed
db timeout
критичных 3
```
